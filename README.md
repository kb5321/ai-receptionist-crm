# Terra Spa CRM

A custom CRM and AI Receptionist platform built with FastAPI, PostgreSQL, OpenAI, RingCentral, Docker, and GitHub.

## Features

* Lead Management
* Client Management
* Appointment Tracking
* SMS Messaging via RingCentral
* User Authentication
* Role-Based Access Control
* Password Reset
* Audit Logging
* Docker Container Support
* Docker Compose Support

## Technology Stack

### Backend

* Python
* FastAPI
* PostgreSQL

### Integrations

* OpenAI API
* RingCentral SMS API

### DevOps

* Docker
* Docker Compose
* Git
* GitHub
* Ubuntu (WSL2)
